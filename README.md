# Task-2-Data-cleaning-and-preprocessing
Titanic Dataset Data Cleaning and Preprocessing using Python, Pandas, and Scikit-learn. Includes missing value handling, duplicate removal, outlier treatment, feature normalization, and a cleaned dataset.
# Task 2: Data Cleaning and Preprocessing

## Objective

To clean and preprocess the Titanic dataset using Python and Pandas.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## Tasks Performed

1. Loaded the Titanic dataset.
2. Examined dataset structure and statistical summary.
3. Identified and handled missing values.
4. Removed the Cabin column due to excessive missing data.
5. Checked and removed duplicate records.
6. Detected and handled outliers using the IQR method.
7. Normalized numerical features using MinMaxScaler.
8. Saved the cleaned dataset.

## Final Result

* Original Dataset Shape: (891, 12)
* Final Dataset Shape: (775, 11)

## Outcome

The dataset was successfully cleaned and prepared for further analysis and machine learning tasks.
